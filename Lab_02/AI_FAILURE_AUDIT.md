### AI_FAILURE_AUDIT.md
When AI generates wrong code or code that does not meet the requirements, record the problem in this file, including:
1. **Original Prompt**
   - The prompt given to AI that caused the error.
2. **AI-Generated Code**
   - The wrong code generated by AI.
3. **Technical Error**
   - What the technical error is and why it happened.
4. **Error Detection Method**
   - How the error was found: using DevTools, Console, `git diff`, or checking for harmful code.
5. **Manual Fix**
   - How to fix the error manually.
   - Only ask AI for help if you cannot fix it yourself.

## Exercise 1: Building Mini-React VNode & Mounting Engine

### Defect 1: `document is not defined`

1. **Error Description:** When testing `test-runner.js`, running `node test-runner.js` caused `ReferenceError: document is not defined`.

2. **Technical Root Cause:** The error occurred because Node.js does not provide the browser's `document` object.

3. **Error Detection Method:** Found the error in the VS Code Terminal and searched for the error message using Google Search.

4. **Manual Fix:** Created an `index.html` file to run and test the code in a browser instead of Node.js.

## Exercise 2: Reactive State Machine & Delegation Hub

### Defect 2.1: MIME Type `text/jsx` Error

1. **AI-Generated Code:**
   - AI named the file `app.jsx`.

2. **Technical Error:**
   - The browser cannot compile `.jsx` files directly.
   - The server returned MIME type `text/jsx` instead of a valid JavaScript module type.

3. **Error Detection Method:**
   - Opened Chrome DevTools Console and found the error message.

4. **Manual Fix:**
   - Renamed `app.jsx` to `app.js`.
   - Updated the script path in `index.html` from `./app.jsx` to `./app.js`.
